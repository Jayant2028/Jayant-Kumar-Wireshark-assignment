# Wireshark Network Traffic Analysis Assignment

This repository contains a Wireshark-based network traffic analysis assignment. The analysis uses packet-capture data to inspect common network protocols, IP addresses, ports, MAC addresses, and packet counts.

## Assignment Overview

The assignment demonstrates practical use of **Wireshark display filters** to analyze captured network traffic and extract useful networking information.

## Topics Covered

- DHCP packet analysis
- ARP packet analysis
- DNS traffic analysis
- TCP and UDP packet analysis
- SMB packet analysis
- IPv4 traffic filtering
- HTTP packet inspection
- NBNS packet analysis
- Source and destination IP identification
- Source and destination port analysis
- MAC address identification
- Packet-count analysis
- Capture-duration analysis

## Tools Used

- Wireshark
- Network packet capture (`.pcap` / `.pcapng`)
- Wireshark display filters

## Learning Outcomes

After completing this assignment, the learner should be able to:

- Capture and inspect network packets using Wireshark.
- Apply protocol-specific display filters.
- Identify source and destination IP addresses.
- Analyze TCP/UDP ports.
- Inspect MAC addresses.
- Count packets matching specific conditions.
- Understand traffic generated by common networking protocols.
